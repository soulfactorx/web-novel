# 웹소설 리더

이 저장소의 `novels/` 폴더에 올린 텍스트 파일을 GitHub Pages 웹페이지에서 읽는 리더입니다.

- **표지**: 서재가 작품별 표지 카드로 표시됩니다. 표지가 없으면 제목으로 기본 표지를 만들어 보여줍니다.
- **여러 파일**: 서재에서 작품(폴더)을 고르면 그 안의 파일 목록이 나오고, 위쪽 탭으로 열어 둔 파일 사이를 오갈 수 있습니다 (최대 8개).
- **이어 읽기**: 보던 위치(문단 단위)가 브라우저에 자동 저장되고, 다시 열면 그 위치로 돌아갑니다. 서재 맨 위에 최근 읽은 작품이 진행률과 함께 표시됩니다.
- **암호화 파일**: `.txt.enc` 파일은 비밀번호를 입력해야 열립니다 (AES-256-GCM, PBKDF2 60만 회). 복호화는 브라우저 안에서만 이루어집니다.
- **목차/페이지**: `제12화`, `12화`, `프롤로그`, `Chapter 3` 같은 줄을 자동으로 찾아 목차를 만들고, 화 단위로 페이지를 나눕니다. ←/→ 키로 페이지를 넘길 수 있습니다.
- **이전/다음 화**: 한 화씩 파일을 나눠 올렸다면, 파일의 처음/끝에서 이전/다음 버튼(또는 ←/→ 키)으로 같은 폴더의 이전/다음 파일로 넘어갑니다. 파일은 이름순(숫자 인식)으로 정렬되므로 `001화`, `002화` 처럼 번호를 붙여 주세요.
- **보기 설정**: 글자 크기, 줄 간격, 본문 폭, 문단 간격, 명조/고딕, 밝게/세피아/어둡게 테마.
- **인코딩 자동 인식**: UTF-8, UTF-16, EUC-KR(CP949) 텍스트 파일을 모두 읽습니다.

## 처음 설정

1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
2. `main` 브랜치에 push 하면 `.github/workflows/pages.yml` 이 소설 목록을 만들고 사이트를 배포합니다.
   (Actions 탭에서 **리더 배포** 워크플로를 수동 실행할 수도 있습니다.)
3. 배포가 끝나면 `https://<사용자명>.github.io/web-novel/` 에서 읽을 수 있습니다.

> 비공개 저장소에서 GitHub Pages 를 쓰려면 유료 플랜(Pro 등)이 필요하고, 그 경우에도 **페이지 자체는 공개**됩니다.
> 남이 보면 안 되는 내용은 아래처럼 암호화해서 올리세요.

## 소설 올리기

`novels/` 아래에 `.txt` 파일을 넣고 push 하면 됩니다. 하위 폴더는 서재에서 작품별 묶음으로 보입니다.

```
novels/
  작품A/
    1권.txt
    2권.txt
  작품B/
    본편.txt.enc     ← 암호화된 파일
```

GitHub 웹에서 **Add file → Upload files** 로 올려도 똑같이 동작합니다.

## 표지 이미지

이미지(`jpg`, `png`, `webp`, `gif`, `avif`)를 텍스트 파일 옆에 두면 표지로 쓰입니다.

```
novels/
  작품A/
    cover.jpg        ← 작품 표지 (cover.* 또는 표지.*)
    1권.txt
    2권.txt
    2권.jpg          ← 2권만의 표지 (텍스트와 같은 이름)
```

- 같은 이름의 이미지가 있으면 그 파일의 표지, 없으면 폴더의 `cover.*` / `표지.*` 가 쓰입니다.
- 폴더에 표지가 없으면 그 안의 파일 표지 중 하나가 작품 표지로 쓰입니다.
- 세로 3:4 비율, 수백 KB 이하 이미지를 권장합니다.
- 표지도 암호화할 수 있습니다 (`cover.jpg.enc`). 암호화된 표지는 그 브라우저에서 비밀번호를 한 번 입력한 뒤부터 보이고,
  그 전에는 🔒 가 붙은 기본 표지로 보입니다.

## 암호화해서 올리기

방법 1 — 브라우저: 배포된 사이트의 `encrypt.html` (보기 설정 패널의 "파일 암호화 도구")에서 텍스트나 표지 이미지를 고르고
비밀번호를 넣으면 `.enc` 파일이 내려받아집니다. 파일은 어디에도 전송되지 않습니다.

방법 2 — 명령줄 (Node.js 18 이상):

```sh
node tools/encrypt.mjs 원고/1권.txt            # → 원고/1권.txt.enc
node tools/encrypt.mjs 원고/cover.jpg          # → 원고/cover.jpg.enc
node tools/encrypt.mjs --decrypt novels/작품B/본편.txt.enc
```

주의할 점:

- **원본 `.txt` 는 커밋하지 마세요.** 한 번이라도 커밋하면 나중에 지워도 Git 기록에 남습니다. 저장소 밖에서 암호화한 뒤 `.enc` 만 올리세요.
- 파일 **이름과 크기**는 암호화되지 않습니다. 제목을 숨기려면 파일 이름을 바꿔 두세요.
- 비밀번호를 잊으면 복구할 수 없습니다.
- 리더에서 "이 기기에 비밀번호 기억하기"를 체크하면 그 브라우저에 비밀번호가 저장됩니다. 공용 기기에서는 체크하지 마세요.
  체크하지 않아도 브라우저 탭을 닫기 전까지는 다시 묻지 않습니다.

## 복사·캡처 방지

`assets/config.js` 의 `protect` 항목으로 켜고 끕니다 (기본값: 문구 워터마크만 꺼짐).

| 설정 | 동작 |
| --- | --- |
| `copy` | 본문 선택·복사·우클릭·드래그 막기, Ctrl+A/C/S/P/U 막기, 인쇄 시 빈 페이지 |
| `blurOnLeave` | 창이 포커스를 잃거나 다른 탭으로 가면 본문을 흐리게 가림 |
| `printScreen` | PrintScreen 키를 누르면 본문을 잠시 가리고 클립보드를 비움 |
| `watermark` | 본문 위에 옅은 문구를 반복 표시 (예: `'개인 열람용'`) — 캡처본 유출 억제용 |

**한계**: 웹페이지에서는 복사·캡처를 완전히 막을 수 없습니다. 휴대폰 스크린샷, 다른 기기로 화면 촬영,
개발자 도구, 브라우저의 읽기 모드 등은 막지 못하며, 일반적인 방법을 번거롭게 만드는 정도입니다.
또 암호화하지 않은 `.txt` 는 저장소와 사이트 주소에서 파일 그대로 받을 수 있으므로,
보호가 의미 있으려면 **암호화(.enc)와 함께** 써야 합니다.

## 새로고침과 웹앱 설치

- 상단의 **⟳ 버튼**은 브라우저 캐시를 건너뛰고 리더 코드와 소설 목록을 다시 받아 새로 고칩니다 (읽던 위치는 유지).
  새 파일을 올렸거나 기능이 업데이트됐는데 화면이 그대로일 때 누르세요. 보기 설정 패널 아래쪽에서 현재 버전(커밋 해시)도 확인할 수 있습니다.
- **웹앱 설치**
  - Android / PC Chrome·Edge: 보기 설정 → **홈 화면에 설치**, 또는 주소창의 설치 아이콘
  - iPhone / iPad: Safari 공유 버튼 → **홈 화면에 추가**
- 설치하면 주소창 없이 앱처럼 열리고, 한 번 연 파일은 오프라인에서도 읽을 수 있습니다.
  항상 서버의 최신 파일을 먼저 확인하고, 연결이 없을 때만 저장된 사본을 씁니다.
- iPhone 에서는 홈 화면 앱과 Safari 의 저장 공간이 따로라서 읽기 기록·비밀번호가 공유되지 않습니다.
  필요하면 **읽기 기록 내보내기/가져오기** 로 옮기세요.

## 읽기 기록

읽은 위치는 브라우저(localStorage)에 저장되므로 기기마다 따로입니다. 다른 기기로 옮기려면
보기 설정 → **읽기 기록 내보내기** 로 받은 파일을 다른 기기에서 **가져오기** 하세요.

## 로컬에서 미리 보기

```sh
node tools/build-index.mjs     # novels/index.json 생성
python3 -m http.server         # http://localhost:8000
```
